# 课堂搭子

在浏览器中导入名单、标记请假、随机均衡分组，并在每节课不重复抽取小组。

## 使用

1. 导入包含“姓名”表头的 `.xls` 或 `.xlsx` 名单；有学号时在姓名后显示学号，没有学号的同名同学则显示名单序号。支持 GB2312 编码、内容实际上为 HTML 表格的 `.xls` 考勤表。
2. 勾选请假的同学，设置每组人数上限并开始分组。人数无法整除时，各组人数相差最多一人，且不超过设定上限。
3. 分组结果每页最多显示 30 组，可翻页或点击“全屏展示”供课堂投影；按 Esc 或点击“退出全屏”返回。屏幕较小或组内人数较多时，可能需要滚动查看。
4. 前往“幸运抽组”，每次随机抽取一个尚未抽过的小组。重新分组或修改出勤会清除本节课的抽取记录。
5. 公共电脑上课结束后，点击“清除本机数据”并确认。

名单、分组和抽取记录仅保存在当前浏览器的本地存储，不会上传服务器。不同设备和浏览器之间不会同步；关闭网页不会自动清除，公共电脑上请主动清除。原始名单文件不会被删除。

## 本地运行

需要 Node.js 22 或更新版本：

```bash
npm ci
npm run dev
```

按终端提示在浏览器打开页面。`npm test` 运行测试，`npm run build` 将静态网站生成到 `docs/`。

## 发布到 GitHub Pages

1. 创建 GitHub 仓库，将**本目录内的项目文件**推送到仓库的 `main` 分支。不要上传真实名单；名单应在网页中由教师本地导入。
2. 在仓库 Settings → Pages → Build and deployment 中，将 Source 设为 **Deploy from a branch**，选择 `main` 分支和 `/docs` 目录。
3. 更新网站时，先运行 `npm test` 和 `npm run build`，再将源代码与生成的 `docs/` 一起提交并推送。GitHub Pages 会发布更新后的静态文件。

如需手动部署，可将 `npm run build` 生成的 `docs/` 目录发布到任意静态网站托管服务。
